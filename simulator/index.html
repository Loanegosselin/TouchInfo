How to use it

  1. Choose an example or draw directly on the grid.
  2. Keep shapes large, distinct and separated.
  3. Add a short audio sentence for optional detail.
  4. Export the dot matrix as JSON for future DotPad integration.

Keyboard: arrow keys move the cursor, Space toggles a dot, D selects draw mode and E selects erase mode.

Browser prototype only. This simulator does not communicate with physical DotPad hardware yet.
